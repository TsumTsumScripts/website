# Guides

Step-by-step walkthroughs for getting things done with the Tsum Tsum script and GAP Companion. Each one starts from
what you need, goes through it screen by screen, and ends with what to do when something doesn't work.

## Tsum Tsum script

- **[Set up with the starter tool](/starter)**: install GAP and the script on a phone or emulator from your
  computer.
- **[Features guide](/features)**: what each feature does, how to turn it on, and every setting.

## GAP Companion

GAP Companion is the phone app and web dashboard for the devices running the script. See
[the Companion page](/companion) for what it adds.

- **[Connect GAP to GAP Companion](companion/connect.md)**: link a device, start the script from your phone, and turn
  on alerts. Start here.
- **[Workflows, step by step](companion/workflows.md)**: build a plan each device follows on its own (hearts, rounds,
  Tsum swaps, presets, restarts), with four complete examples.

Stuck on something a guide doesn't cover? Ask in the Discord: the link is at the top of every page.
